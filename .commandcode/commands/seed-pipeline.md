Ejecuta el pipeline de seed de quizzes.

Pasos disponibles (ejecutar en orden si se pide "full"):
1. `npm run seed:polish` — Normalizar seed generado
2. `npm run seed:covers` — Generar covers procedurales
3. `npm run seed:stock-covers` — Hydrate con stock covers (Pexels/Pixabay)
4. `npm run seed:supabase:import` — Importar a Supabase

Si se indica un paso específico, ejecutar solo ese.
